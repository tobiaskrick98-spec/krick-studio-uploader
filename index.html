Krick Studio Uploader

Content distribution tool for athlete creators

Krick Studio Uploader is a content-distribution pipeline built for professional athletes who run their own social-media presence. It ingests short-form videos the creator has produced, applies channel-consistent metadata (title, description, hashtags), and publishes them as YouTube Shorts on a predictable daily cadence.

The tool was built to solve a concrete problem: top-tier athletes generate a high volume of short-form footage during training, matches, and travel, but lack the bandwidth to manually upload to every platform on a consistent schedule. Krick Studio Uploader removes the manual step on YouTube while keeping the creator in full control of which clips go live.

What it does

Queue management

The creator curates a ranked queue of short-form clips. Each entry has its own title, description, tags, and visibility setting.

Scheduled upload

Once per day, the next-highest-ranked clip is published as a YouTube Short to the creator's own channel.

Hard daily cap

By design, at most one upload per calendar day to protect channel cadence and avoid algorithmic penalties.

Single-user, single-channel

The tool authenticates to exactly one Google account and uploads to exactly one YouTube channel — the creator's own.

Who uses it

Krick Studio Uploader is currently used by Tobias Krick, a German professional volleyball player and content creator (@tobiaskrick, 12.8k+ YouTube subscribers, 140+ videos). It is offered as a template for other athlete creators who want to set up the same workflow on their own infrastructure.

Google account access

Krick Studio Uploader requests access to the following Google API scopes, used only for the purposes listed:

  • youtube.upload — to publish the creator's own short-form videos to the creator's own YouTube channel.
  • youtube — to set video metadata (title, description, tags, category, visibility) on those same uploads.
  • youtube.readonly — to read the channel's upload history so the daily-cap logic can verify whether a video has already been published that day.

The tool does not read, modify, or transmit any data outside the creator's own YouTube channel. It does not share data with any third party.

Where the code runs

Krick Studio Uploader runs on a single private server controlled by the creator. Authentication tokens are stored on that server only. There is no shared backend, no analytics, no telemetry. The creator can revoke access at any time at myaccount.google.com/permissions.
